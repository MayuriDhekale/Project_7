# Project_7
<br>
<b>4-Layer STM32F407 Industrial Development Board</b>
<br>
Designed and developed a custom 4-layer STM32F407VGT6 development board intended as a flexible platform for embedded and industrial communication applications.
The board uses the STM32F407VGT6 microcontroller and includes USB Type-C, CAN, RS-485, UART, I²C, SPI, SWD, and GPIO interfaces. It also has a 3.3V power supply, reset and boot circuit, 8 MHz and 32.768 kHz crystals, and expansion headers for connecting external devices.
